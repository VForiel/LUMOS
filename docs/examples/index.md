# Examples

Step-by-step Jupyter notebooks, stored in the
[`examples/`](https://github.com/VForiel/LUMOS/tree/main/examples) directory of the repository with the
presets they use (`examples/presets/*.lumos`). Each preset of the web interface matches one of them. They are
executed by the test suite and when this documentation is built, so their figures appear below. Each page
starts with buttons to open the notebook on Google Colab or Binder.
