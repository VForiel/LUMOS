# LUMOS

**Lumos is a Universal and Modular Optical Simulator & Operating System.**

LUMOS simulates light end to end, from a scene (astronomical, terrestrial or laboratory) to the detected data,
through any optical system. The same object model drives real optical equipment, builds data processing
pipelines and is exposed to AI assistants through an MCP server.

:::{warning}
LUMOS is in early development. This documentation describes the planned structure; most pages are placeholders.
